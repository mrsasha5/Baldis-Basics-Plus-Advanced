# Baldis-Basics-Plus-Advanced
This is a source code of the [Baldi's Basics Plus: Advanced Edition](https://gamebanana.com/mods/504169)!<br>
This project is made for the game Baldi's Basics Plus.<br>
Modification adds a new character, random events, structures, activities and more for this game.<br>
There is no exact theme of content, content may be different and of any type.
# Minimal Dependencies
- .NET Standard 2.0
- "[BepInEx](https://github.com/BepInEx/BepInEx)" v5.4.22 dependencies
- "[Baldi's Basics Plus Development API](https://gamebanana.com/mods/383711)" made by [MissingTextureMan101](https://gamebanana.com/members/1665049)
- "[Level Loader System](https://gamebanana.com/mods/617565)" made by [MissingTextureMan101](https://gamebanana.com/members/1665049)
- Libraries of the original game located in "BALDI_Data/Managed" folder
